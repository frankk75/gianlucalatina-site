ACCESSO AMMINISTRATORE

Gestisci foto e promozioni

L'area pubblica resta su GitHub Pages. Per pubblicare modifiche serve un token GitHub personale con accesso in scrittura al solo repository del sito.

Il token resta solo nella sessione del browser e viene cancellato quando esci o chiudi la sessione. Non viene salvato nei file del sito.

Come creare il token
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Consenti l'accesso solo al repository frankk75/gianlucalatina-site.
  3. Permesso Repository → Contents: Read and write.
  4. Copia il token e incollalo qui.
